# elmanualdealex.com

My personal website and portfolio.

This repository contains the source code for **elmanualdealex.com**, a platform where I showcase my projects, professional experience, technical skills, achievements, and interests in software engineering, cybersecurity, technology, and entrepreneurship.

## Purpose

The website serves as:

- Portfolio
- Resume (CV)
- Project showcase
- Personal blog
- Professional profile
- Contact point

## Tech Stack

### Frontend

- TypeScript
- React
- Next.js
- Tailwind CSS

### Backend

**Current**

**Future**

- Express.js
